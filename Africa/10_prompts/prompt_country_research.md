# Prompt — Fiche pays

Utilisez ce prompt avec l’outil Claude :

```
Tu es analyste marché spécialisé en transformation digitale publique en Afrique.

Prépare une fiche pays complète pour : [PAYS].

Contexte de notre firme :
- Petite firme canadienne de conseil IT/data/AI
- 2 spécialistes data
- 1 analyste d’affaires
- Services : data governance, BI/dashboarding, AI readiness, data engineering, M&E dashboards, MIS/ERP, cloud modernization
- Capacité francophone et anglophone

Recherche demandée :
1. Stratégie digitale nationale
2. Stratégie data ou IA
3. Programmes financés par World Bank, AfDB, AFD, GIZ, UNDP, UNICEF, EU, Enabel
4. Opportunités actives ou probables
5. Organisations à contacter
6. Partenaires locaux potentiels
7. Risques
8. Plan d’action commercial

Format :
Utilise le template country_research_template.md.

Règles :
- Priorise les sources officielles.
- Mets un niveau de confiance : High / Medium / Low.
- Si une opportunité est inférée, écris clairement “inférence”.
- Termine avec 5 actions concrètes à faire cette semaine.
```
